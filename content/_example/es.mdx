# Documento de contenido de ejemplo

Este es un marcador de posición que demuestra la convención
`content/<slug>/<locale>.mdx` (consulta `content/README.md`). Elimina
`content/_example/` cuando exista contenido real.

El verificador de compilación (`scripts/check-content.mjs`) exige que este slug
también tenga un archivo hermano `en.mdx`.
